# Lume

Landing page em português de Portugal para o Lume 1.0, teleponto e gravação para macOS 15+.

Site estático: HTML, CSS e JavaScript, com imagens promocionais geradas para o projeto e downloads Intel e Apple Silicon. Sem dependências de build.

## Deploy
Importar este repositório no Vercel com Framework Preset: Other e diretório raiz.
